Acerca de mi

Soy ingeniero industrial y desarrollador de aplicaciones multiplataforma, con amplia experiencia en el diseño y optimización de sistemas tecnológicos para Android, iOS, Windows y la web. Combino conocimientos en gestión de procesos industriales con habilidades en desarrollo de software para crear soluciones eficientes y escalables que mejoren la productividad y la experiencia del usuario.

Trabajo con tecnologías como Node.js, Express, React Native, así como lenguajes como Java y C#. Además, aplico metodologías ágiles para la planificación y ejecución de proyectos, asegurando resultados efectivos en entornos dinámicos y colaborativos.

Mi objetivo es integrar la ingeniería industrial con el desarrollo tecnológico para impulsar la innovación, optimizar procesos y ofrecer soluciones digitales que respondan a los desafíos del mercado actual.
